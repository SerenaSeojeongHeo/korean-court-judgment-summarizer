# Korean Court Judgment Summarizer

A Python-based legal text processing project designed to generate concise and structured summaries of Korean court judgments.

The project aims to explore how natural language processing can be used to make lengthy judicial decisions easier to review, while preserving key legal information such as the facts, issues, reasoning, and outcome of a case.

## Overview

Korean court judgments can be lengthy and structurally complex, making it time-consuming to identify the key facts and legal reasoning.

This project provides a simple workflow for processing judgment text and generating a structured summary that highlights the most relevant parts of a decision.

The project was developed as a practical exploration of the intersection between law, language, and technology.

## Key Features

- Processes Korean court judgment text
- Identifies key information from lengthy legal documents
- Generates concise case summaries
- Organises summaries into legally meaningful sections
- Designed for legal research and information retrieval use cases
- Provides a foundation for further development using NLP and large language models

## Summary Structure

The output is designed to include information such as:

- Case overview
- Relevant facts
- Main legal issues
- Court reasoning
- Final decision
- Key legal principles
